## Mini Project: Login Form

# Overview

This is a simple, responsive login form built as a mini-project to demonstrate fundamental skills in HTML, CSS, and JavaScript. The form performs real-time input validation, handles common edge cases, and authenticates against hardcoded credentials without a backend server.

The project meets the following requirements:

Built using only vanilla HTML, CSS, and JavaScript.

No external libraries or frameworks were used.

Authenticates using hardcoded credentials.

Provides dynamic UI feedback to the user.

Features
Real-time Validation: Input fields are validated as the user types, providing immediate feedback for empty fields or invalid email formats.

Hardcoded Authentication: The form checks credentials against a predefined email and password stored in the JavaScript file.

Dynamic Feedback: Displays clear error messages for invalid inputs and a success/failure message upon form submission.

Responsive Design: The form's layout is optimized for both desktop and mobile screens.
