# Reflection

What I Planned:
- Add one high-impact, low-effort feature based on feedback: persistence with localStorage.

What I Built:
- Local storage of tasks, automatic reload on page load, storage updates on add/toggle/delete.

What Went Well:
- Minimal changes to the core structure.
- Clear separation of concerns via helpers.

What I Learned:
- Importance of saving on each interaction (source of truth can be DOM or data model).
- Value of small UX cues (hint text) to showcase new capabilities.

What I'd Improve Next:
- Sorting and filtering tasks.
- Accessibility enhancements (ARIA, focus management, keyboard navigation).
